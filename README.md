# 崖瀑 · 夜（Cliff Night）

9:16 竖构图的生成艺术动画：蓝色夜空下一块黑色山体，
垭口处泻下一股宽流，逐级分岔成越来越细的水柱，末端散入水潭。

- 背景：蓝色夜空（漂浮星尘微粒）+ 黑色山体（柏林噪声山脊）
- 水流：手绘分支树 + はぅ君 StaircaseWaterway 噪声运动
  （fork of tp5_250806_StaircaseWaterway, credits to はぅ君）
- 每根水柱的落点高低、横移远近各自随机，柱底溅水花

## 运行

直接打开 `index.html`（加载 p5.js CDN），或访问 GitHub Pages。

## 操作

- 点击：暂停 / 继续
- R：重新铺水
- S：保存图片
- ↑/↓：调山高；←/→：调山脊起伏
